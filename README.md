## 👨‍💻 About the Project

Welcome to my **Artificial Intelligence Lab Experiments** repository!

This project contains **10 practical AI experiments implemented using Python and Jupyter Notebook**. It explores fundamental Artificial Intelligence concepts, including search algorithms, optimization, game-playing strategies, backtracking, and classic problem-solving techniques.

The goal is to connect theoretical knowledge with practical implementation and develop a strong foundation in AI algorithms.

## 🎯 Experiments Included

| No. | Experiment | What You Will Learn |
|---:|---|---|
| 01 | 🔍 Breadth-First Search (BFS) | Traverse graphs level by level using a queue. |
| 02 | 🌳 Depth-First Search (DFS) | Explore graph nodes using recursion. |
| 03 | ⛰️ Hill Climbing | Understand heuristic-based optimization. |
| 04 | 🗺️ A* Search Algorithm | Find paths using path costs and heuristics. |
| 05 | 🎮 Minimax Algorithm | Select optimal moves in adversarial games. |
| 06 | ✂️ Alpha-Beta Pruning | Reduce unnecessary Minimax search. |
| 07 | ♟️ Eight Queens Problem | Apply backtracking to avoid queen conflicts. |
| 08 | 💧 Water Jug Problem | Solve a measuring problem through state-space search. |
| 09 | ❌ Tic-Tac-Toe | Explore game logic with a two-player game. |
| 10 | 🚗 Travelling Salesman Problem (TSP) | Find a minimum-distance tour by checking possible routes. |

## 🛠️ Technologies Used

- **Python** — implementing algorithms and problem-solving logic.
- **Jupyter Notebook** — writing code, executing experiments, and viewing results.
- **Core AI concepts** — graph traversal, heuristic search, recursion, optimization, game theory, and backtracking.

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/Artificial-Intelligence-Lab.git
```

Replace `YOUR-USERNAME` with your GitHub username.

### 2. Open the project folder

```bash
cd Artificial-Intelligence-Lab
```

### 3. Install Jupyter Notebook

```bash
python -m pip install notebook
```

### 4. Launch Jupyter Notebook

```bash
jupyter notebook
```

Open any `.ipynb` file in your browser and run its cells sequentially. Some notebooks may require additional Python packages depending on their implementation.
